# Fictional Resume Fixtures

This directory contains seven fictional resumes created for application testing and demonstration. Names, contact details, employers, schools, and experience descriptions are invented. Email addresses use the reserved `example.com` domain, and telephone numbers use the fictional 555 range.

The fixture set includes:

- Three TXT resumes.
- Two DOCX resumes.
- Two PDF resumes.
- Mixed capitalization of the keyword Python.
- Resumes with and without Python experience.
- A resume without an education section.
- A resume without a telephone number.

Regenerate the files from the repository root with:

```bash
python scripts/generate_sample_resumes.py
```
